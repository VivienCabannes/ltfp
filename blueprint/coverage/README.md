## Completion rules

- `MAPPED` means the source area has a reviewed coarse milestone and exercise ownership.
- `DETAILED` means the milestone has reviewed theorem-sized pages in the Autoform DAG.
- A node is complete only when its statement and proof are formalized here, or when the
  pinned Mathlib checkout already supplies it.
- Whole-source completion requires every milestone to be detailed; the current seven
  detailed milestones do not imply completion of the full book.

The authoritative exercise matrix and Phase 1 attestation remain in the repository under
`sources/`; this page summarizes them for the published blueprint.
